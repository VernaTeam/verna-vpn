# ورنا وی‌پی‌ان

یک اپ اندرویدی که تونل sing-box را با کانفیگ‌های رایگان و عمومی بالا می‌آورد — و
قبل از اینکه هیچ‌کدام را به شما پیشنهاد بدهد، همه‌شان را روی گوشی خودتان تست می‌کند.

---

## مسئله‌ای که واقعاً حل می‌کند

کمبود کانفیگ رایگان نداریم. کانال‌های تلگرام روزی هزاران تا می‌گذارند. مشکل این
است که تقریباً هیچ‌کدام **از جایی که شما هستید** کار نمی‌کنند، و این را یکی‌یکی
می‌فهمید: کپی، اتصال، انتظار، شکست، دوباره از اول.

تست سمت سرور این را حل نمی‌کند. کانفیگی که یک دیتاسنتر در آلمان به آن می‌رسد،
ممکن است از یک شبکهٔ موبایل ایرانی اصلاً در دسترس نباشد — چون چیزی که جلویش را
گرفته بین شما و سرور است، نه بین سرور و دنیا.

پس ورنا از روی خود دستگاه اندازه می‌گیرد. نمونه‌ای از استخر را می‌گیرد، از هستهٔ
sing-box در حالت پروکسی رد می‌کند، و آن‌هایی را نشان می‌دهد که واقعاً ترافیک عبور
دادند — با پینگی که گوشی شما اندازه گرفته، نه عددی که کسی دیگر گرفته.

تفاوتش کم نیست. روی یک Galaxy J7 با اینترنت خانگی، از ۳۱۳ سرور نامزد:

| | تعداد |
|---|---|
| چیزی که سرور تأیید کرده بود | ۳۱۳ |
| چیزی که واقعاً از اینجا سوکت TCP قبول کرد | ۱۹۱ |
| چیزی که واقعاً از اینجا ترافیک عبور داد | **۵۱** |

فهرستی که می‌بینید، سطر سوم است.

## آن قسمتی که از تصور سخت‌تر بود

کانال کنترل خود اپ، دقیقاً گرفتار همان فیلترینگی است که اپ برای دور زدنش ساخته شده.

API کانفیگ‌ها پشت Cloudflare است. Cloudflare انی‌کست است، یعنی هر آدرس لبه همان
سایت را سرو می‌کند — ولی از یک خط ایرانی فقط بعضی از آن آدرس‌ها در دسترس‌اند، و
اینکه کدام‌ها، در طول روز عوض می‌شود. اندازه‌گیری ۱۱ شهریور ۱۴۰۵: آدرسی که DNS
برگرداند تایم‌اوت می‌شد، در حالی که هشت لبهٔ دیگر Cloudflare همان API را در حدود
یک ثانیه جواب می‌دادند. سرور تمام این مدت سالم بود.

برای همین زیر هر درخواست سه لایه هست:

۱. **چرخش بین لبه‌ها** — اگر آدرسی که DNS داد مرده بود، مستقیم به یک لبهٔ شناختهٔ
Cloudflare وصل شو. TLS همچنان نام واقعی دامنه را حمل می‌کند، پس گواهی دقیقاً مثل
قبل بررسی می‌شود؛ فقط مقصد سوکت عوض می‌شود. لبه‌ای که جواب داد یادش می‌ماند تا
دفعهٔ بعد دوباره تایم‌اوت‌ها را نپردازیم.

۲. **کش روی دستگاه** — آخرین فهرستی که رسیده، فقط وقتی شبکه شکست بخورد.

۳. **فهرست همراه بیلد** — نمونه‌ای از استخر که داخل خود APK است، برای اولین اجرا
روی خطی که بقیهٔ راه‌ها را بسته. ظرف چند روز کهنه می‌شود، و دقیقاً برای همین آخرین
گزینه است؛ هر ردیفش قبل از پیشنهاد شدن، روی دستگاه دوباره تست می‌شود.

فایل `assets/seed_configs.json` در این مخزن خالی است. محتوایش عکسی از سرورهای
دیگران است، و تاریخچهٔ گیت جای ماندگاری برای چیزی نیست که یک هفته دیگر کهنه شده.
قبل از بیلد ریلیز پرش کنید:

</div>

```bash
python tool/fetch_seed_configs.py
```

<div dir="rtl">

اپ فایل خالی را «بدون فهرست پشتیبان» در نظر می‌گیرد و بدون آن هم درست کار می‌کند.

هیچ‌کدام از این‌ها بررسی گواهی را ضعیف نمی‌کنند.

## چه چیزهایی دارد

- **پروتکل‌ها** — VLESS (با Reality)، VMess، Shadowsocks، Trojan، Hysteria2 و
TUIC، از طریق sing-box نسخهٔ ۱.۱۴.
- **تست روی دستگاه** — دسته‌های بیست‌تایی از urltest خود هسته، تا اندازه‌گیری مال
سرور باشد نه مال صفی که پشتش ایستاده؛ و هر دسته دو بار سنجیده می‌شود تا سروری که
مسابقهٔ اول را باخت، مرده حساب نشود.
- **DNS روی HTTPS و پورت ۴۴۳**، از داخل تونل. UDP ساده اینجا جواب نمی‌دهد: بیشتر
کانفیگ‌های رایگان فقط TCP هستند، و نتیجه‌اش تونلی بود که بایت جابه‌جا می‌کرد ولی
هیچ اسمی را resolve نمی‌کرد.
- **اتصال دوبارهٔ خودکار** وقتی شبکه عوض می‌شود، با یک بازهٔ آرام‌گیری تا جابه‌جایی
وای‌فای به موبایل، یک نشست سالم را قطع نکند.
- **تاریخچهٔ مصرف** — بایت به تفکیک روز برای دو هفته، فقط روی خود دستگاه و بدون
ارسال به هیچ‌جا.
- **فارسی و انگلیسی**، روشن و تاریک، با تعویض زنده.

## چیزهایی که هنوز ساخته نشده

قطع اضطراری، تونل انتخابی و دسترسی به شبکهٔ محلی در تنظیمات به‌جای سوییچ، با برچسب
«به‌زودی» نشان داده می‌شوند. سوییچی که جابه‌جا شود و هیچ کاری نکند، از نبودن یک
قابلیت بدتر است — مخصوصاً قطع اضطراری، که کل وجودش یک قول است دربارهٔ اینکه وقتی
تونل بیفتد چه اتفاقی می‌افتد.

## بیلد

به فلاتر ۳.۴۴ به بالا و Android SDK نیاز دارد.

</div>

```bash
flutter pub get
flutter run                       # دیباگ، روی دستگاه متصل
flutter build apk --release       # ریلیز
```

<div dir="rtl">

امضای ریلیز از `android/key.properties` خوانده می‌شود که در این مخزن نیست. بدون
آن، بیلد به کلید دیباگ برمی‌گردد و همین را هم اعلام می‌کند. برای ساختن کلید خودتان:

</div>

```bash
keytool -genkey -v -keystore verna.keystore -alias verna \
  -keyalg RSA -keysize 2048 -validity 10000
```

<div dir="rtl">

بعد فایل `android/key.properties` را بسازید:

</div>

```properties
storePassword=…
keyPassword=…
keyAlias=verna
storeFile=../verna.keystore
```
